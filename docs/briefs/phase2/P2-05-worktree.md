КОНТЕКСТ — Проект ultron, рабочий каталог = корень репозитория: утилита, в которой Claude пишет TaskSpec, исполнитель через Antigravity CLI (agy) делает работу, обратно возвращается TaskResult. Python 3.10, только стандартная библиотека. Ядро и транзакционный цикл на снимках уже работают, все тесты кроме новых зелёные. Этот шаг — режим worktree: задача работает в отдельном git worktree от baseline-снимка, дерево пользователя не трогается до приёмки, результат переносится патчем. Карта — docs/internals.md, раздел «Режим worktree (изоляция задачи)»; тесты — арбитр. Уже готовы и менять их нельзя: ultron/policy.py, ultron/schemas/, tests/, docs/. Гейт запускается из корня рабочего каталога.
